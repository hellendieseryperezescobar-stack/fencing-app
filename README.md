# 🤺 Fencing Pro v2.0

## App multi-arma para esgrimistas y entrenadores

### ¿Qué incluye?
- ✅ **3 armas**: Florete, Espada, Sable (teoría, reglamento, táctica, tests y equipamiento específicos)
- ✅ **2 modos**: Atleta (personal) y Entrenador (gestión de equipo)
- ✅ **17 secciones**: entrenamientos, competencias, combates, oponentes, tests físicos, video análisis, equipamiento, nutrición, psicología, música, objetivos, diario, teoría, lesiones, ranking y calendario

### Cómo usar
1. Abre el archivo `index.html` con Chrome, Safari o Edge
2. Selecciona tu arma (Florete/Espada/Sable)
3. Selecciona tu modo (Atleta o Entrenador)
4. ¡Listo! Todo se guarda en tu dispositivo (offline)

### Cómo instalar como app en el celular
**Android (Chrome):**
- Abre el archivo → Menú ⋮ → "Agregar a pantalla de inicio" → Instalar

**iPhone (Safari):**
- Abre el archivo → Compartir ⬆️ → "Agregar a pantalla de inicio"

### Cómo subir a GitHub Pages (link web)
1. Ve a github.com → New repository → nombre: `fencing-app`
2. Sube el archivo `index.html` (arrastra y suelta)
3. Settings → Pages → Source: Deploy from branch → main / root
4. Espera 1-2 minutos y obtienes tu link: `https://tunombre.github.io/fencing-app`

### Datos
- Los datos se guardan en el navegador (localStorage)
- Si borras el historial/caché, se pierden los datos
- Para respaldar: abre la consola (F12) y escribe: `copy(localStorage.getItem('fencing_pro_v2_multi'))`
