# 🤺 Fencing Athlete Pro

**App de seguimiento para esgrimistas** — Florete Cadete · Selección Venezuela

Una Progressive Web App (PWA) completa para que atletas de esgrima registren entrenamientos, competencias, combates, oponentes, tests físicos, nutrición, psicología, objetivos y más.

---

## 📱 ¿Qué incluye la app?

| Sección | Función |
|---------|---------|
| **Dashboard** | Resumen de estadísticas, próximos eventos, últimos combates |
| **Entrenamientos** | Tipo, duración, intensidad 1-10, notas |
| **Competencias** | Torneos, ubicación, posición final |
| **Combates** | Individual/Equipo, Poule/Directas, score completo, notas tácticas |
| **Oponentes** | Base de datos de rivales + historial H2H (head-to-head) |
| **Calendario** | Vista mensual con eventos marcados |
| **Tests Físicos** | Lanzadera 2-4-2, salto vertical, fondos, desplazamiento 10m |
| **Video Análisis** | Links a YouTube/Drive de combates propios y rivales |
| **Equipamiento** | Control de florete, careta, chaquetilla, cables, etc. |
| **Nutrición** | Vasos de agua, proteínas, carbohidratos, verduras, suplementos |
| **Psicología** | Ejercicios del psicólogo con checkbox de completado |
| **Música** | Playlists: pre-entrenamiento, entrenamiento, pre-competitivo, recuperación |
| **Objetivos** | Metas SMART con barra de progreso |
| **Diario** | Entradas diarias con ánimo, energía, sueño (1-10) |
| **Teoría / Reglamento** | Posiciones, convención de prioridad, táctica, reglamento |
| **Lesiones / Prevención** | Registro de molestias + ejercicios preventivos |
| **Ranking** | Seguimiento de posición nacional, panamericano, FIE |

## 🚀 Cómo instalarla en el celular

### Android (Chrome)
1. Abre el link de tu app en Chrome
2. Chrome te preguntará: **"¿Agregar Fencing Pro a la pantalla de inicio?"**
3. Toca **"Instalar"**
4. ¡Listo! Aparece el ícono 🤺 como cualquier app nativa

### iPhone (Safari)
1. Abre el link en Safari
2. Toca el botón **Compartir** ⬆️
3. Selecciona **"Agregar a pantalla de inicio"**
4. Aparece el ícono como app nativa

> ✅ Funciona **100% offline** una vez instalada
> ✅ Los datos se guardan en el celular (localStorage)
> ✅ Se ve como app nativa: pantalla completa, sin barra de navegador

## 🛠️ Cómo subir a GitHub Pages (paso a paso)

### Paso 1: Crear el repositorio
1. Ve a [github.com](https://github.com) e inicia sesión
2. Haz clic en el botón verde **"New"** (nuevo repositorio)
3. En **Repository name** escribe: `fencing-app`
4. Selecciona **Public** (público)
5. Marca la casilla **"Add a README file"**
6. Haz clic en **"Create repository"**

### Paso 2: Subir los archivos
1. Dentro del repositorio, haz clic en **"Add file"** → **"Upload files"**
2. Arrastra los archivos `index.html` y `README.md` (o selecciónalos manualmente)
3. En **Commit changes** escribe: `Primera versión de la app`
4. Haz clic en **"Commit changes"**

### Paso 3: Activar GitHub Pages
1. Ve a la pestaña **"Settings"** del repositorio (arriba a la derecha)
2. En el menú lateral izquierdo, busca y haz clic en **"Pages"**
3. En **Source**, selecciona **"Deploy from a branch"**
4. En **Branch**, selecciona **"main"** y la carpeta **"/(root)"**
5. Haz clic en **"Save"**
6. Espera 1-2 minutos y GitHub te dará tu link: `https://tunombre.github.io/fencing-app`

### Paso 4: Compartir
- Envía el link por WhatsApp a tu hija
- Ella lo abre en Chrome/Safari y lo instala como app
- ¡Listo para usar!

## 🔄 Actualizar la app en el futuro

Si quieres agregar más funciones:
1. Edita el archivo `index.html` en tu computadora
2. Sube la nueva versión a GitHub (sobrescribe el anterior)
3. GitHub Pages se actualiza automáticamente en 1-2 minutos
4. Los usuarios que ya la instalaron verán los cambios al abrir la app

> ⚠️ **Importante:** Los datos guardados en el celular (entrenamientos, combates, etc.) se mantienen porque se almacenan localmente en el dispositivo, no en GitHub.

---

## 📤 Exportar datos (backup)

Para hacer un respaldo de los datos:
1. Abre la app en el navegador
2. Presiona **F12** (en computadora) → pestaña **Console**
3. Escribe: `copy(localStorage.getItem('fencing_pro_v2'))`
4. Pega el texto copiado en un archivo de texto como respaldo
